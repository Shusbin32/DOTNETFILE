 ASP.NET Core Login/Signup System with Email Verification
This project is a robust Login/Signup system built using ASP.NET Core Identity, Entity Framework Core, and PostgreSQL. It includes full email verification functionality to enhance user account security.

-- Features
- User Registration with Email Verification

- Secure Login with Identity

- SMTP-based Email Verification (Token-based)

-Resend Verification Email

- Password Hashing & Security Best Practices

- Entity Framework Core integration

- PostgreSQL as the backend database

- Tech Stack
ASP.NET Core

ASP.NET Identity

Entity Framework Core

PostgreSQL

SMTP Email Service (mailtrap)

- Setup & Run
Clone the repository

Configure the database connection and email credentials in appsettings.json

Run migrations using EF Core

Launch the application and test registration & login
